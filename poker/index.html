House Rules — Games R Us Poker Night

This page never simulates a hand — it's a companion for a real table with real cards. Add every player before the first hand, set the blind schedule and buy-in in Settings, then hit Start Night. Bump each player's stack up or down between hands using the +/- controls (or after showdown, whichever your table prefers), and mark a player Out the moment they're felted. Blinds step up automatically on the clock you set; use Skip if your table plays faster than the timer. When the last hand's done, hit Finish to lock in standings and see the payout split for the places you configured.
